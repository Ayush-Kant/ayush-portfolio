# Hero asset

The hero intentionally uses one visual asset only:

- `hero-typing-scene.webp`

It is rendered as a full-bleed background image and blended into the portfolio background with layered gradients/masking. Hero copy remains real HTML so typography stays responsive, accessible, selectable, and editable.

No intro video, alternate wave image, typing-hand image, or cat cutout is required by the current implementation.
