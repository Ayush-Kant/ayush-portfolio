Skill Icons SVG bundle for the requested portfolio skills.

Source repository:
https://github.com/tandpfun/skill-icons

Available from the source repository (included):
- Java
- JavaScript
- TypeScript
- Python
- React
- Next.js (NextJS)
- Tailwind CSS (TailwindCSS)
- CSS
- Node.js (NodeJS)
- MongoDB
- PostgreSQL
- Redis
- Docker
- Kubernetes
- AWS
- Git
- GitHub (Github)

Variant notes:
- Separate Dark/Light SVGs exist for: Java, Python, React, NextJS, TailwindCSS, NodeJS, PostgreSQL, Redis, AWS, Github.
- Single SVGs exist for: JavaScript, TypeScript, CSS, MongoDB, Docker, Kubernetes, Git.

Not present in the skill-icons repository's current icons directory:
- LangChain
- LangGraph
- Qdrant
- Pydantic
- Ollama

I did not substitute unrelated third-party assets for those five skills, so the bundle contains only SVGs that were actually found in the requested repository.
